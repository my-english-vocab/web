# 첫 단어장 온보딩

## 사용자 흐름

1. 로그인·회원가입 후 보호된 화면에 진입하면 `/api/onboarding/status`로 단어 유무를 확인한다. 단어가 0개면 `/onboarding`으로 이동한다.
2. 토익 / 수능 영어 / 일상·여행 영어 / 토플·학술 영어 / 오픽·영어 말하기 / 비즈니스 이메일 / IT·개발 문서 중 하나를 고른다.
3. 분야별 초급 2개, 중급 3개, 고급 5개를 순서대로 살펴본다. 영어 단어와 예문을 먼저 보여주고 뜻과 예문 해석은 펼쳐서 확인한다.
4. `알고 있어요` / `모르겠어요`로 응답한다. 객관식 채점이나 실력 등급 판정은 하지 않는다.
5. 결과에서 모르는 단어만 기본 선택한다. 단어별 선택, 전체 선택/해제, 예문 다시 보기, 응답 수정이 가능하다.
6. 선택한 단어의 뜻·예문·번역을 함께 저장한다. 0개 선택도 허용하며 이때 저장 API를 호출하지 않고 홈으로 이동한다.
7. 완료 후 단어장 또는 기존 퀴즈 화면으로 이동한다.

## 상태와 예외 처리

- 자동 진입 판단은 `AuthGuard`의 `OnboardingGate`가 담당한다. `/onboarding` 자체는 자동 진입 확인을 생략해 리다이렉트 반복을 방지한다.
- 건너뛰기는 서버에 단어를 만들지 않는다. 같은 계정·같은 탭의 로그인 세션에서는 다시 자동으로 안내하지 않는다.
- 명시적 로그인 성공 시 세션 확인 표시와 임시 진행을 초기화한다. 따라서 단어가 여전히 0개면 다음 로그인에서 다시 안내한다.
- 쿠키를 이용한 로그인 복원은 초기화하지 않는다. 같은 탭에서 새로고침하면 진행 중인 목적·응답·선택을 복원한다.
- 임시 진행은 계정별 `sessionStorage`에 저장한다. 서버에는 실력 등급이나 응답을 저장하지 않는다. 저장소 이용이 차단되면 메모리로 대체하며 이 경우 새로고침 복원은 지원하지 않는다.
- 카탈로그 버전 불일치 또는 잘못된 임시 데이터는 초기 화면부터 시작한다.
- 자동 진입 확인 실패는 기존 화면 이용을 허용한다. 카탈로그 로딩 실패는 재시도/건너뛰기를 제공한다.
- 저장 중에는 중복 제출과 선택 변경을 막는다. 실패 시 선택을 보존하고 재시도를 제공한다. 서버는 온보딩 동시 저장과 재시도 시 중복 단어를 추가하지 않는다.
- 빈 단어장 홈의 `추천 단어로 시작하기`, 또는 홈 상단 마이페이지 패널의 `추천 단어 다시 만나기`에서 수동으로 시작할 수 있다.
- 마이페이지 패널에서 다시 시작하면 이전에 남은 임시 답변만 지우고 목적 선택부터 시작한다. 이미 저장한 단어는 유지되며, 같은 단어를 다시 선택해도 서버가 중복 추가하지 않는다.

## 구현 위치

- `src/app/onboarding/page.tsx`: 인증 및 카탈로그 로딩
- `src/components/onboarding/OnboardingFlow.tsx`: 목적 → 확인 → 선택 → 완료 UI
- `src/components/onboarding/Onboarding.module.css`: 데스크톱/모바일 화면, 모바일 고정 시작·저장 버튼
- `src/components/onboarding/OnboardingGate.tsx`: 빈 단어장 자동 진입
- `src/lib/onboarding/session.ts`: 계정별 세션 상태
- `src/lib/api/onboarding.ts`: 타입 및 API 호출

단어 원본은 별도 백엔드 저장소의 `src/main/resources/onboarding/catalog.json`에서 관리한다. 프론트엔드에 중복 사본을 두지 않는다. 난이도는 입문 콘텐츠 편집 기준이며 시험 기관의 공식 난이도·빈도 통계가 아니다.

## 검증

`npm run lint`, `npm run test:run`, `npm run build`를 실행한다. 자동 진입, 건너뛰기, 다음 로그인 재진입, 새로고침 복원, 기본 선택/변경, 0개 선택, 저장 실패/중복 제출을 테스트한다. 브라우저에서는 신규 가입 → 목적 선택 → 10개 응답 → 선택 수정 → 저장 → 단어장 반영과 모바일 하단 버튼을 확인한다.

백엔드 API와 함께 적용해야 한다. 새 환경 변수나 프론트엔드 의존성은 필요하지 않다.
